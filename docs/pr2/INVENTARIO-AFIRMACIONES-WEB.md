# Inventario de afirmaciones comerciales de la web (30/09/2026)

Todas quedan **excluidas** de la base de conocimiento y de las respuestas del
agente (el validador rechaza porcentajes, multiplicadores, testimonios y estos
nombres). Este inventario es para decidir qué hacer en la **web**.

Leyenda de la recomendación:
- **Eliminar**: afirmación de resultado o de clientela sin acreditar.
- **Etiquetar**: maqueta visual; mantener solo si se marca como "Ejemplo ilustrativo".
- **Sustituir**: cambiar por un dato acreditable o por texto cualitativo.
- **Mantener**: dato correcto y acreditable.
